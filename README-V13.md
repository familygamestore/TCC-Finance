# TCC Finance V13 Ultra UI

V13 menggunakan V10/V12 visual foundation dan memperbaiki akses Super Admin, Event Hub, Kas & Brand, responsive layout, drawer-based forms, quick money buttons, dark/light mode, dan hydration-safe landing/dashboard.

## Local
cd frontend
npm.cmd install
npm.cmd run typecheck
npm.cmd run build
npm.cmd run dev

## Vercel
Root Directory: frontend
Framework: Next.js
Output Directory: default
Environment Variable: NEXT_PUBLIC_APPS_SCRIPT_URL
