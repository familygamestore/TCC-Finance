# TCC Finance Assets

Letakkan asset custom di folder ini.

- logo/: logo utama, dark/light, icon
- hero/: gambar landing page / dashboard
- brands/: logo brand seperti MONGSTER, TCC, SHOCKWAVE
- icons/: icon tambahan
- placeholders/: gambar fallback

Gunakan nama file yang stabil agar mudah direferensikan dari Next.js public path.
